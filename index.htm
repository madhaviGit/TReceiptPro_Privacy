AI Processing

Receipt images and data are processed by Google Gemini AI to extract information such as merchant name, date, total amount, and line items. Images sent to Gemini are used solely for extraction purposes and are not stored or used for AI training by the Service Provider. Processing is subject to Google's Gemini API Terms and Privacy Policy.

Bank Statement Import

When you use the bank statement import feature, we process the PDF or CSV file you select. From that file we extract:

  • Transaction date
  • Merchant / payee name
  • Raw transaction description
  • Amount and currency
  • Inferred expense category

Before any data is sent for AI extraction, sensitive values such as Social Security Numbers and labelled account numbers are automatically masked.

How it is processed:

  1. Your file is uploaded to Firebase Storage under a path scoped to your user account (bankStatements/{yourUserId}/).
  2. The file is scanned for malware using VirusTotal. On the free tier, uploaded files are analysed on the public VirusTotal platform. Files that fail the scan are rejected and deleted immediately.
  3. A backend Cloud Function reads the file, strips embedded metadata, masks sensitive identifiers, and sends the sanitised text to Google Gemini for transaction extraction.
  4. Extracted transactions are written to your private Firestore document (users/{yourUserId}/bankStatements/{importId}).
  5. You can review, edit, and selectively save them to your expense records.

File retention: The original uploaded file (PDF/CSV) is deleted automatically as soon as processing completes — whether it succeeds, fails, or is rejected by the virus scan. A storage lifecycle rule enforces a hard maximum retention of 24 hours in the event of an unexpected server failure.

Extracted data retention: Structured transaction data saved to your account is retained until you delete it from within the app or request account deletion.

Data deletion: You can delete individual transactions from the app. To delete all imported bank statement data or your account, contact us at projects.madhavi@gmail.com or use the account deletion option in Settings.
